# The Microsoft Store's pictures (store/README.md): Stage.cs's language, run with
# `dotnet run scripts/stage/Stage.cs -- store shots [scene]`. Stage px are 3072 x 1728 at 200 %, the bar
# along the bottom. No captions here: compose.mjs puts each picture's headline beside it. Never a
# right click on a pin: its jump list is the person's own (recent chats, files).
# A scene's wallpaper is the stage's usual one (Stage.cs's Wallpaper.Usual) unless it names another of
# store/wallpapers.json: the desktops differ from page to page, as they do on Themia's.
